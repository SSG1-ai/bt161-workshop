The exercises

EXERCISE 0

Getting Started

Log in to SAP LeanIX, open the AI Agent Hub, and orient yourself in the interface.

 EXERCISE 1

The AI Agent Hub Dashboard

Create an Architecture Decision Record, review the dashboard, and link the ADR to a verified agent.

 EXERCISE 2

From Discovery to Inventory

Open your agent in the Discovery Inbox, review the discovery details, and add it to the inventory.

 EXERCISE 3

Complete the Governance Profile

Assign subscribers, validate the description, and link the Architecture Decision.

 EXERCISE 4

Collect Missing Information via Survey

Generate an AI survey, send it to the business owner, and apply the response to the fact sheet.

 EXERCISE 5

Verify the Agent

Complete the checklist, set the lifecycle to Active, mark as Verified, and set the Quality Seal.

 EXERCISE 6

Decommission a Legacy Agent

Link the ADR and successor, set End of Life, and reject the verification of a legacy agent.
